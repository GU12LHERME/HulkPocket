# GLES real stencil and optional guest Clear hook

Based on verified XDK 5849 state definitions and NV097 stencil op encodings, the GLES backend now clears stencil independently of write mask, tracks full initialization, and supports compare, mask, fail/depth-fail/pass operations. Solid fill and smooth shading are accepted; unknown states identify the index/value. Pixel tests cover stencil writing with disabled color writes, equality and failure, and masked clears. Optional D3DDevice_Clear is intercepted only if the generated symbol exists, using the verified six-stack-argument ABI and live device ownership. Pending direct packets must drain successfully before Clear and guest target switches still stop. The clear is offscreen and is not an original presented frame. Draw/Swap and raw configuration translation remain pending. This work is independent of the next RP6 log; CI and real-device verification are required.
