# Memory statistics checkpoint

RP6 b8a7c03: XLaunchNewImageA(null, launch data) returned the supported missing-image error, then real game execution reached MmQueryStatistics (181). Implement the 36-byte Xbox MM_STATISTICS ABI using a 64 MiB retail profile, 4 KiB Xbox pages, live contiguous allocation pages, virtual reservations/commit, unique live pool pages, worker/main stacks and mapped image pages. Cache backing is not implemented and reports zero committed cache pages. Free-page totals are a diagnostic approximation, not exact Xbox PFN accounting: independent host arenas are not yet globally constrained to 64 MiB. Source references: TGP482/XboxXBERecomp runtime/kernel/memory.cpp and xboxkrnl.cpp, Cxbx-Reloaded EmuKrnlMm.cpp. Tests check invalid length, allocation delta, and virtual reservation/commit. Unsupported kernel calls now dump the recent call trace. No change to generated code/cache.
