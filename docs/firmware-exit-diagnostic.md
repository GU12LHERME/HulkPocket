# Firmware exit checkpoint

RP6 revision 5e2fa23 completed DPC initialization and MmPersistContiguousMemory at 83FFF000 for 4096 bytes, then called HalReturnToFirmware (ordinal 49). This is a non-returning guest exit or reboot request, not an ordinary missing kernel function. The actual cause was not visible in the previous log.

The pinned XboxXBERecomp runtime/xdk/xapi.cpp rejects XLaunchNewImageA for executables without a recompiled image with ERROR_FILE_NOT_FOUND. The USA Hulk config names XLaunchNewImageA at 00209C04. The portable runtime now links a strong override using the generated symbol and validates the result in the ELF. Unsupported external launches return that error; self-relaunch explicitly stops until reboot support exists. The kernel exit logs reason, return address, checked launch page header and target path plus a bounded 48-entry recent kernel trace. KeBugCheck also prints its caller and trace. No Android restart or filesystem writes, no unconditional skip of guest reboot. Test coverage includes the returning strong symbol and error ABI.
