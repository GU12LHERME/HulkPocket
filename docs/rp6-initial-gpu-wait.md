# RP6 GPU wait and first offscreen swap checkpoint

The d1f336a device run rendered two reduced-profile line draws (1208 vertices, 1066 white pixels). Local command-context report proves 0038A2C0 reads the global device slot 0039DFA8, the completion pointer at CDevice+30 and current time +2C, then polls, with two stdcall arguments and ret 8. The earlier ARM64 offset 1FA8 is the displacement of the global slot from the static device base, not a command-object field. The pinned upstream labels the analogous operation D3D_BlockOnTime. Locally verify the exact generated instruction landmarks and weak alias before linking a strong adapter. Only after successful reduced draw continuation, on the owner thread, drain supported state packets and use the GLES synchronous finish path. Accept initial zero target/current and flags 1/2/4 only, no callback, maximum 32 waits; all other epochs, callbacks and modes remain unsupported. No fake guest hardware completion pointer or arbitrary fence timeline. If original Swap(0) is reached, capture the actual backbuffer, execute EGL pbuffer presentation and stop without returning to guest. This is offscreen and reduced-profile, not a complete faithful frame, Android window, or gameplay. CI and RP6 validation pending.
