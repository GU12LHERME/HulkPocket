# GLES viewport and local writer investigation

On RP6, 0930820 assembled 1020 original XYZ+diffuse vertices, but the device's viewport was zero. cba5ef5 added a reduced diagnostic replay (not a faithful frame) and logs changes between owner-thread callbacks. This update implements real nonzero XYZ viewport rectangles and depth ranges in GLES, translating top-left D3D coordinates to GL bottom-left. It rejects zero/out-of-target rectangles and keeps partial XYZRHW unsupported until clipping semantics are established. Pixel tests cover asymmetric viewport placement, mapped depth comparisons and invalid bounds. The diagnostic additionally logs target header words when viewport changes and shows local generated instruction context at the previous/current callback return addresses. Those contexts bracket changes; they do not prove the exact writer. No guest draw return or raw-packet bypass is added. CI and RP6 verification pending.
