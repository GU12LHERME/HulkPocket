# Batched storage and mobile validation update

Based on a591b7d (signed TLS fix awaiting RP6). eb4c2f9 RP6 logs show all 26 original reads succeed, but four D: size queries return STATUS_NOT_SUPPORTED and partition1 TDATA OPEN_IF returns missing, leading to an attempted dashboard launch. This batch implements read-only optical logical size from actual extracted regular file sizes (2048-byte sectors, zero free, not a physical XISO geometry). Measurement is bounded and cached for the session; no file content reads and no host symlink traversal. Adds actual NtQueryDirectoryFile class 1 using the Xbox ANSI record layout, one entry per call, restart, wildcard filter, short-buffer retry, EOF and event completion. Other info classes and APCs remain unsupported. The new mobile installer verifies exact git revision, SHA256 and ARM64 ELF before atomic replacement, rejects overlapping disc/partition roots, prepares private TDATA and UDATA directories and title subdirectories for 56550039 without following symlinks. Runtime remains read-only for both roots; this is not save support. Tests cover actual payload size, wildcard enumeration, retry, restart, symlink exclusion, wrong ZIP revision/checksum and safe partition setup. The GLES workflow now triggers on fiber and filesystem changes to publish a matching artifact. No gameplay, shader or rendering changes claimed. Next validation requires RP6, especially the first signed TLS switch.
