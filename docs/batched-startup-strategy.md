# Batch startup compatibility

Verified USA XPP descriptor table 003EA754..003EA764 and indirect call 003EAC68 from actual device trace. Discover missing callbacks with file-backed executable prologue checks; reject different executable/caller, do not scan arbitrary code words. Single mobile command `bash tools/run_hulk_next.sh` discovers seeds, invokes incremental compiler, retains private original/cache, links runtime, runs diagnostic and produces fresh timestamped TXT. RP6 report a3bb430 confirmed discovery ran and returned missing seeds but there was no executable named xbe_recomp_host. The command now builds the upstream host recompilation tool natively with existing CMake recipe in ~/hulk-recompiler-native when needed, using two build jobs to limit memory and heat. Requires Termux cmake, clang, make, git and network to fetch pinned CMake dependencies; HULK_RECOMPILER can point to a trusted locally built compatible executable. Optional HULK_DISC_ROOT. New kernel batch includes cooperative per-thread IRQL transitions with DPC deferral, timer handles and timer cancellation/scheduling (non-APC, non-resume only), dispatcher handle duplication, nonalertable event/semaphore signal-and-wait, timer multiwait consumption and shutdown-state query. Not full hardware IRQL, APC, named objects, real shutdown, file/thread handle duplication or playable graphics. Tests use synthetic memory; device generated source remains private. Native tool build on RP6 remains unvalidated.
