# Batch startup compatibility

Verified USA XPP descriptor table 003EA754..003EA764 and indirect call 003EAC68 from actual device trace. Discover missing callbacks with file-backed executable prologue checks; reject different executable/caller, do not scan arbitrary code words. Single mobile command `bash tools/run_hulk_next.sh` discovers seeds, invokes incremental compiler, retains private original/cache, links runtime, runs diagnostic and produces fresh timestamped TXT. If multiple or no host recompilers found, requires explicit HULK_RECOMPILER. Optional HULK_DISC_ROOT. New kernel batch includes cooperative per-thread IRQL transitions with DPC deferral, timer handles and timer cancellation/scheduling (non-APC, non-resume only), dispatcher handle duplication, nonalertable event/semaphore signal-and-wait, timer multiwait consumption and shutdown-state query. Not full hardware IRQL, APC, named objects, real shutdown, file/thread handle duplication or playable graphics. Tests use synthetic memory; device generated source remains private.
