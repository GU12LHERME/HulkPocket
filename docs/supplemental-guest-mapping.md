# Recover existing generated guest functions

RP6 local report confirmed VA 003CF9B8 is a file-backed executable DSOUND function with its own generated X86_FUNC body in partition 124, but no primary mapping entry. Its instructions store a global pointer and return. The cached relinker now scans actual generated partition bodies and matching weak aliases, adds only exact unmapped address-named function starts inside the original code range, and emits a supplemental header outside the fingerprinted tree. The native linker must resolve all added symbols; no original function body, absent trap stub, or interior label is synthesized. The in-module dispatcher validates the union of both maps and rejects duplicate/out-of-range entries. Host and ARM64 fixtures exercise an actual indirect call to a supplemental body and reject an interior address. Named symbols without address-based aliases are not covered. No change to original game objects or build fingerprint; local RP6 validation pending.
